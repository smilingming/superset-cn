# M3a Pure i18n Overlay

This directory contains only Apache Superset Chinese language resources.

Allowed files:
- superset/translations/zh/LC_MESSAGES/messages.po
- superset/translations/zh/LC_MESSAGES/messages.mo
- superset/translations/zh/LC_MESSAGES/messages.json

Scope:
- language resources only
- no UI asset replacement
- no page shell replacement
- no auth page change
- no runtime feature expansion
